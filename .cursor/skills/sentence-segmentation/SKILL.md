# 分句（Sentence Segmentation）

## 目标
把输入文本切分为句子序列，便于后续逐句事件抽取。

## 输入
用户会提供：

- 一段文本（通常来自上一步 `text-preprocess-coref` 的 `resolved_text`）

## 输出（必须严格只输出 JSON）
输出一个 JSON object：

- `sentences`: 数组，每个元素：
  - `id`: 句子 id，格式必须为 `s1`, `s2`, ...
  - `sentence`: 句子文本
  - `offset_hint`: 可选，简述该句在全文的大致位置（例如“开头/中段/结尾”）

分句规则（尽量遵守）：

1. 以中文句号、问号、叹号、分号为主要边界：`。！？；`。
2. 对“但是/然而/同时/并且/此外/随后/之后/因此”等连接词：
   - 如果连接词后是相对独立子句，可以拆成两句。
3. 对引号内文本：尽量保持整体，不要把一段直接引语拆得过碎。
4. 去除空句。

约束：

- **只输出 JSON，不要 Markdown，不要解释文字**。
