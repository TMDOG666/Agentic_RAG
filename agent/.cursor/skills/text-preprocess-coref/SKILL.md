# 文本预处理与指代消解（通用）

## 目标

给定一个较长的中文/中英混合叙述文本：

1. 基于上下文补全省略的句法主语（如果可以高置信补全）。
2. 做指代消解：把代词/指示词（如“他/她/它/他们/该公司/该机构/上述/此事/该行为”）尽可能替换为明确指代对象。
3. 输出可复用的结构化结果，供后续分句与事件抽取使用。

## 输入

用户会提供一段原始文本（可能包含多句）。

## 输出（必须严格只输出 JSON）

输出一个 JSON object，字段如下：

- `resolved_text`：完成主语补全与指代消解后的全文（尽量保持原意，不要臆造新事实）
- `coref_map`：数组，记录替换关系
  - `mention`：原始指代片段（如“他”“该公司”“此事”）
  - `resolved_to`：被解析为的实体/事件指代（字符串）
  - `confidence`：0-1
  - `note`：简短原因（可选）
- `inserted_subjects`：数组，记录你补全主语的地方
  - `original_fragment`
  - `rewritten_fragment`
  - `subject`
  - `confidence`

约束：

1. **只输出 JSON，不要 Markdown，不要解释文字**。
2. 如果无法确定指代对象：
   - 不要强行替换，保持原文
   - 仍可在 `coref_map` 里记录 `resolved_to: null` 并说明原因
3. 主语补全只做“高置信”的补全（confidence < 0.6 则不要改写原句）。

## 特殊情况

- 如果实在上下文无主语请看[[references/特殊情况.md]]

## 建议策略

- 优先识别：人名、组织名、地点、产品/系统名、时间表达。
- 将“该公司/该机构/上述”优先指向最近出现且语义匹配的实体。
- 对“此事/该行为/这次操作”优先指向最近一个可被当作事件的描述。
